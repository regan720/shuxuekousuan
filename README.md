# 小题大作

一个面向小学 1-6 年级的数学口算题生成与打印工具。选择年级和题型后，可以自动生成 A4 练习页，并按需要调整题量、列数、页数、字号和题号显示，适合家庭练习、课堂小测或日常刷题使用。

## 功能特点

- 覆盖小学 1-6 年级常见口算题型
- 支持按年级选择题型，也可以多题型混合生成
- 自动去重并生成随机练习题
- 支持 A4 页面预览和浏览器打印
- 可调整每页题数、每行列数、页数和题目字号
- 可选择是否显示题号
- 纯前端静态页面，无需后端服务

## 题型范围

应用内置 47 类口算题型，包含：

- 一年级：10 以内加减法、20 以内进退位、人民币换算、大小比较等
- 二年级：表内乘除法、有余数除法、万以内加减法、长度和重量单位换算等
- 三年级：乘除混合、同分母分数、一位小数、时间和面积单位换算等
- 四年级：小数加减、估算、小数点移动、四则混合、运算定律等
- 五年级：小数乘除、分数加减乘除、体积容积换算、公因数和公倍数等
- 六年级：百分数、比、负数、折扣税率利率、圆和圆柱圆锥相关计算等

## 使用方法

1. 打开页面后，在左侧选择年级。
2. 勾选需要练习的题型，或点击当前年级的“全选”。
3. 在“版式”中设置每页题数、每行列数、页数和题目字号。
4. 如需重新换一套题，点击“重新生成”。
5. 确认右侧 A4 预览后，点击“打印”。

## 本地运行

这是已经构建好的静态站点，直接打开 `index.html` 即可使用。

如果浏览器安全策略导致本地文件加载异常，可以在当前目录启动一个静态服务：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 适用场景

- 家长为孩子快速生成每日口算练习
- 教师制作课堂小测或课后练习
- 学生按薄弱题型进行专项训练
- 打印成纸质练习页，减少手工出题时间
