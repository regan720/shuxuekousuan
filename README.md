# 小题大作

一个用于生成小学 1-6 年级口算练习题的本地网页工具，支持按年级和题型生成 A4 打印页，也支持通过自定义 AI 模型生成数学题。

## 在线页面

本仓库存放的是构建后的静态页面产物，可直接用于 GitHub Pages 或其它静态站点托管。

入口文件：

```text
index.html
```

## AI 生成题目

进入左侧 `AI 生成题目` 切页后，可以配置 OpenAI 兼容格式的模型接口，并输入需要生成的数学题型。

处理流程：

1. 优先匹配系统已有题型；
2. 匹配成功时直接使用内置规则生成；
3. 未匹配到现有题型时，判断输入是否与数学题相关；
4. 非数学内容会拒绝生成；
5. 新的数学题型会通过配置的 AI 模型生成。
